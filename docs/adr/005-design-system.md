# ADR 005 — Design system próprio

**Estado:** aceito.

## Contexto

O projeto precisa de identidade brasileira, UX clara para câmera/permissão e componentes consistentes sem uma biblioteca visual pesada.

## Decisão

Tokens CSS, DM Sans, Instrument Serif e ícones Lucide. Componentes semânticos Button, Tag e Toggle. Dialog nativo, foco visível, movimento reduzido, layout responsivo e feedback textual.

## Consequências

Interface coerente e leve. A equipe mantém e testa seus componentes. Referências de sinais são esquemáticas e exigem revisão linguística; quatro letras são melhores que 26 referências não verificadas. A prática é apresentada como manual até existir avaliação automática validada.
